🤖 ai-landing-page
Landing page responsiva sobre Inteligência Artificial nos tempos modernos, desenvolvida com HTML5 e CSS3 puro como entrega de checkpoint acadêmico.

📋 Descrição
Página web de uma única página (single-page) que apresenta de forma visual e estruturada o tema da Inteligência Artificial, abordando suas principais áreas de atuação e conceitos fundamentais.
O projeto foi desenvolvido com foco em:

Estruturação semântica com HTML5
Estilização moderna com CSS3 e variáveis customizadas (--css-variables)
Layout com Flexbox
Tipografia com Google Fonts (Inter)
Design limpo e minimalista com paleta azul, branco e preto


🖥️ Seções da página

Hero — Título principal, chamada para ação e imagem de destaque
Áreas de Atuação — Cards com as 4 principais tendências da IA:

IA Generativa & Criativa
Mobilidade Autônoma
Negócios & Dados
Agentes Autônomos


Sobre IA — Definição e pilares da inteligência artificial
Footer — Identificação dos autores


🚀 Como usar
Não requer instalação. Basta abrir o arquivo diretamente no navegador:
bash# Clone o repositório
git clone https://github.com/seu-usuario/ai-landing-page.git

# Abra o arquivo no navegador
cd ai-landing-page/checkpoint-02
open index.html
Ou simplesmente dê dois cliques no arquivo index.html.
